# 🎮 Main Controller (`main.js`)

계산기의 **상태 관리와 사용자 입력을 총괄하는 컨트롤러 모듈**입니다.

---

## 📌 역할
* `calculator.js`(계산)와 `ui.js`(화면)를 연결하는 진입점(Entry Point)입니다.
* 사용자의 조작(클릭, 키보드)을 감지하여 적절한 기능을 실행합니다.

---

## ⚙️ 주요 기능
* **상태 기억 (State Management)**: 현재 누르고 있는 값(`current`), 직전에 누른 값(`previous`), 대기 중인 연산자(`operator`)를 저장합니다.
* **마우스 클릭 바인딩**: 숫자, 연산자, 등호(=), 지우기(C) 버튼 클릭에 맞게 계산 함수를 호출하고 화면을 새로고침합니다.
* **키보드 단축키 지원**: 키보드의 숫자패드, 사칙연산(`+`, `-`, `*`, `/`), Enter, ESC 키 입력을 인식해 대응하는 버튼을 동작시킵니다.

---

# 🎨 Style & Design (`style.css`)

레트로 하드웨어의 **입체적인 디자인과 레이아웃을 담당하는 스타일 시트**입니다.

---

## 📌 역할
* 계산기 외형, 색상 팔레트, 버튼 배치, 인터랙션 효과를 정의합니다.

---

## ⚙️ 주요 특징
* **레트로 컬러 테마**: 올리브 그린, 다크 그레이, 빈티지 디스플레이 배경색을 CSS 변수(`:root`)로 관리합니다.
* **4열 그리드 키패드**: CSS Grid(`repeat(4, 1fr)`)를 사용해 버튼을 바둑판 형태로 균등 배치합니다.
* **물리 버튼 클릭 피드백**: 그림자와 `:active` 가상 선택자를 적용해 누를 때 살짝 들어가는 입체감을 제공합니다.
* **디스플레이 텍스처**: 옛날 전자계산기/CRT 화면 느낌을 내기 위해 미세한 가로 줄무늬(스캔라인) 패턴을 적용했습니다.

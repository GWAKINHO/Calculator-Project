# 🧮 Calculator Module (`calculator.js`)

화면 표시나 디자인과 분리된 **순수 수학 연산 전담 모듈**입니다.

---

## 📌 역할
* 화면(DOM)을 직접 건드리지 않고, 입력받은 값으로 사칙연산 및 수치 변환만 수행합니다.
* 언제든 독립적으로 테스트하고 재사용할 수 있는 순수 함수로 구성되어 있습니다.

---

## ⚙️ 주요 기능
* **`compute(a, b, op)`**: 두 숫자($a, b$)와 연산자(더하기, 빼기, 곱하기, 나누기)를 받아 결과를 계산합니다. (0으로 나눌 경우 에러/NaN 반환)
* **`toggleSign(str)`**: 현재 숫자의 부호를 양수(+) ↔ 음수(−)로 반전합니다.
* **`computePercent(str)`**: 현재 숫자를 100으로 나누어 백분율 값으로 환산합니다.

---

# 🖥️ UI & Display Module (`ui.js`)

계산 결과를 **화면에 보기 좋게 출력하고 시각적 상태를 제어하는 모듈**입니다.

---

## 📌 역할
* 계산기 화면(디스플레이)의 텍스트 갱신을 담당합니다.
* 숫자가 화면을 벗어나 깨지지 않도록 자릿수를 조절합니다.

---

## ⚙️ 주요 기능
* **`formatNumber(numStr)`**: 긴 숫자를 화면 크기에 맞게 10자리 내외로 다듬거나 지수 표기법(`1e+12` 등)으로 변환합니다.
* **`updateDisplay(current, previous, operator)`**: 위쪽 수식창(`expr`)과 아래쪽 결과창(`result`)에 최신 값을 출력합니다.
* **연산자 활성화 강조**: 사칙연산 버튼이 눌려 있을 때 해당 버튼에 테두리 불(`op-active`)을 켜서 시각적으로 알려줍니다.

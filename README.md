# 📱 Web Calculator Project

> 웹 브라우저 환경에서 동작하는 직관적이고 가벼운 웹 계산기 애플리케이션입니다.

---

## 📖 1. 프로젝트 소개
* **주제**: HTML, CSS, JavaScript를 기반으로 구현된 인터랙티브 사칙연산 계산기입니다.
* **주요 기능**:
  * 숫자 입력 및 사칙연산(`+`, `-`, `×`, `÷`) 실시간 디스플레이 표시
  * 입력된 수식의 정규식 검증을 통한 안전한 계산 실행
  * `0으로 나누기` 등 예외 상황 발생 시 `Error` 처리 및 초기화(`C`) 기능
  * CSS Grid 기반의 반응형 버튼 레이아웃 지원

---

## 🛠 2. 개발 및 실행 환경
* **OS**: Windows 11 / macOS / Linux (크로스 플랫폼)
* **언어 및 기술 스택**: 
  * HTML5
  * CSS3 (Grid Layout, CSS Variables)
  * Vanilla JavaScript (ES6+)
* **개발 도구**: Visual Studio Code
* **실행 환경**: 최신 웹 브라우저 (Chrome, Edge, Safari, Firefox 등 별도 설치 불필요)

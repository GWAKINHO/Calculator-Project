

### 3. 기능 폴더 안의 `README.md` (기능별 상세)

`basic-calculator` 폴더 안에 위치할 기능 설명 파일입니다.

```markdown
# 🧩 기능 모듈: 기본 계산기 (Basic Calculator)

이 폴더는 사용자의 버튼 클릭 이벤트를 감지하여 사칙연산을 수행하고 화면에 결과를 표시하는 **핵심 계산기 UI 및 연산 모듈**을 포함하고 있습니다.

---

## 📌 1. 기능 설명
* **담당 역할**:
  * 그리드(Grid) 형태의 숫자 및 연산자 키패드 UI 렌더링
  * 사용자 입력을 수식 문자열(`expr`)로 결합하고 화면(`display`)에 실시간 반영
  * 등호(`=`) 클릭 시 입력된 수식의 안정성을 검증한 뒤 사칙연산 수행
* **입력 및 출력**:
  * **Input**: 사용자의 키패드 클릭(`0-9`, `+`, `-`, `×`, `÷`, `.`, `C`, `=`)
  * **Output**: 계산 결과 값 또는 비정상 연산 시 `Error` 출력

---

## 💻 2. 소스코드 구성 및 파일별 역할

| 파일명 | 파일 구분 | 상세 역할 및 핵심 로직 |
| :--- | :--- | :--- |
| `basic_calculator.html` | UI & Script | • HTML Grid를 이용한 4열 버튼 배치<br>• `buttons` 2차원 배열을 순회하여 버튼 동적 생성<br>• `press(val)` 함수를 통한 상태 관리 및 연산 |

---

## 📚 3. 핵심 로직 설명

* **문자열 치환 및 유효성 검증**:
  * 화면 표시용 기호 `×`, `÷`를 자바스크립트 연산 기호 `*`, `/`로 변환합니다.
  * 정규식 `/^[0-9+\-*/.() ]+$/`를 사용하여 지정된 숫자 및 연산자 이외의 비인가 스크립트 실행을 방지합니다.
* **연산 처리 및 부동소수점 오차 보정**:
  * 엄격 모드(`"use strict"`)의 익명 함수를 생성하여 문자열 수식을 계산합니다.
  * 자바스크립트 특유의 소수점 계산 오차(예: `0.1 + 0.2 = 0.30000000000000004`)를 방지하기 위해 `Math.round(result * 1e10) / 1e10` 처리를 적용했습니다.
* **예외 처리**:
  * `0`으로 나누거나 수식이 잘못된 경우 `isFinite()` 검사와 `try-catch` 블록을 통해 `Error`를 안전하게 출력합니다.
